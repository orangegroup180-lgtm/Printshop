How to Add New Photos

1. Copy your new image into the assets/images/ folder.
2. Open assets/js/gallery.js in any text editor.
3. Add a new line to the GALLERY_IMAGES array at the top of the file following the existing format.
4. Push to GitHub — the gallery updates automatically!
